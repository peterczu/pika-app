Automated Deployments

☁️

Cloud Native

The application runs as a containerized workload on AWS using managed cloud services.

🔐

Secure Access

GitHub Actions authenticates to AWS through OIDC rather than relying on long-lived AWS credentials.

📦

Containerized

The application is packaged as a Docker image and stored in Amazon ECR for deployment.

🔄

Versioned Releases

Each application build can be associated with a Git commit, providing traceability between source code and deployment.

🛡️

Least Privilege

The application deployment role receives only the permissions required to publish images and update the ECS service.
